# Contributing

Open an issue describing the observed failure, affected revision, reproduction steps and expected result. For fixes, submit a focused pull request with a regression case and CI evidence. Follow README instructions for local checks.

Keep cloud provisioning disabled. Use synthetic inputs and disposable offline tests. Preserve upstream license notices when adapting examples. Contributions are submitted under the project Apache 2.0 license.

Maintainers review changes to workflows and policy checks together with code changes. Passing checks are required before merging.
