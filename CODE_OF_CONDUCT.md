# Code of conduct

ARCHNET welcomes contributors regardless of experience, nationality, ethnicity, gender, disability, religion or personal background. Treat people respectfully, give specific technical feedback, and accept corrections in good faith.

Harassment, threats, discriminatory language, sexual attention, publication of private information without consent, and repeated personal attacks are unacceptable. These standards apply in project issues, pull requests and other project-managed spaces.

Report concerns privately to Edwin Jonathan at edwinjonathanchibuike123@gmail.com. Include links and relevant context. The maintainer will review reports confidentially, avoid sharing personal information unnecessarily, and consider the reporter's safety when responding. Response times are best effort.

Enforcement can include a request to edit or remove content, a warning, temporary restrictions, or removal from project participation. Repeated or severe misconduct may result in immediate removal. Decisions should explain the conduct at issue and the restriction imposed while preserving private information.

If a report concerns the maintainer, contributors may use GitHub's reporting tools for conduct on GitHub. This project currently has one maintainer and has no independent project appeals panel.
