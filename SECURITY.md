# Security policy

Report suspected vulnerabilities privately through the repository Security tab using Report a vulnerability. Include the affected revision, reproduction steps and expected impact. Omit secrets and customer data.

The preview is experimental. Reports are triaged by the maintainer on a best-effort basis. There is no guaranteed response time or production support commitment.

CI includes a HIGH/CRITICAL filesystem scan and regression tests. These checks have defined scope and do not constitute a comprehensive security assessment.
